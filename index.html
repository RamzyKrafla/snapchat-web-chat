Snap Chat

This page is only the installer. Chat stays on Snapchat’s own site.

  1. Turn on Settings → Safari → Request Desktop Website → All Websites.
  2. Install the free Userscripts app, then open snapchat-web.user.js and add it there. Allow it on www.snapchat.com.
  3. Open Snap Chat home screen icon and allow the profile. An icon named Snap Chat appears.

The icon opens https://www.snapchat.com/web/ in Safari. Log in there. Spotlight controls are hidden. Chat stays.
